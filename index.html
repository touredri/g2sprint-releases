Installer en trois étapes

Une connexion internet suffit le temps du téléchargement. Ensuite, G2Sprint marche hors ligne.

  1. Téléchargez

    Cliquez sur « Télécharger pour Windows ». Le fichier arrive dans le dossier Téléchargements.

  2. Ouvrez le fichier

    Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis sur Exécuter quand même.

    Windows a protégé votre ordinateur
    Informations complémentaires
    Exécuter quand même

  3. Choisissez votre activité

    Boutique, restaurant, pressing, quincaillerie… G2Sprint prépare les bons outils et un catalogue de départ.

Ce qu’il vous faut

  • Un ordinateur WindowsWindows 10 ou 11. Pas besoin d’un ordinateur récent.
  • Une imprimante de tickets58 ou 80 mm, en USB ou Bluetooth. Facultative pour commencer.
  • Internet, juste une foisPour télécharger, puis pour les mises à jour si vous le souhaitez.

Vous utilisez déjà G2Sprint sur téléphone ?

Faites une sauvegarde dans l’application du téléphone, copiez le fichier sur l’ordinateur, puis choisissez « Récupérer les données de mon téléphone » au premier lancement. Vos articles, ventes et clients vous suivent.
